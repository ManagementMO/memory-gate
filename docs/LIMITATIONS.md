# Current limitations — October 23, 2026

This is a tested local foundation, corresponding to Level B in the Heirloom brief. It is not yet Level C presentation readiness. The current audit and PLAN_ALIGNMENT.md distinguish implemented, automated, provider and human evidence.

The intended audience is now adults with **younger-onset Alzheimer’s (diagnosed before 65)** and people close to them. Age at diagnosis does not specify disease stage or individual ability. The simplified view, stable camera, unhurried acknowledgments and source labels are design decisions, not evidence of clinical safety, effectiveness or improved cognition. There has been no patient pilot or clinician review. Before use with affected participants, involve them in design, assess individual comfort, and offer screen-only participation and an immediate break.

The Alzheimer’s Association describes reminiscence as an activity aimed at connection and following the person’s lead, distinct from professionally structured therapy: [reminiscence guidance](https://www.alz.org/help-support/caregiving/daily-care/reminiscence-and-reminiscence-therapy), [communication guidance](https://www.alz.org/help-support/caregiving/daily-care/communications), and [younger-onset information](https://www.alz.org/alzheimers-dementia/what-is-alzheimers/younger-early-onset). The [2018 Cochrane review](https://www.cochrane.org/evidence/CD001120_reminiscence-therapy-dementia) found small, context-dependent effects of reminiscence interventions; it does not validate this app, generative VR, or a younger-onset-specific benefit.

Common English/Spanish uncertainty and memory-testing phrases have code-side safeguards. Other languages still depend on model behavior and family review. A plausible illustration can introduce false details, even when a relative confirms it. Shared approval records a choice about the scene, not objective historical truth. The illustrative backdrop’s architecture, vegetation and table are authored scenery and are labeled separately from source-linked spoken objects.

- **Physical Quest 3 is unverified.** Native controller grab/release and gate selection passed in the actual IWSDK immersive emulator. That does not establish physical stereo, frame pacing, microphone permission inside XR, passthrough, hand tracking or comfort. Follow QUEST_CHECKLIST.md with a wearer.
- **No real family review.** Audio checks used explicitly synthesized English/Spanish speech through the real capture and STT path. A relative's accent/dialect, microphone and interpretation need their review. The initial keepsake is an original symbolic illustration.
- **Bounded spatial vocabulary.** Supported English/Spanish moves and turns of existing objects use a guided deterministic parser. Ordinary narration uses Claude. Arbitrary multilingual spatial reasoning, recoloring an existing accepted prop and attaching arbitrary narration to any selected existing object are not complete.
- **Transcript repair is limited.** The original recognized transcript is preserved. A participant can dismiss a wrong proposal and use the typed command/form; there is no inline edit of a captured transcript before submission.
- **Generated worlds are interpretations.** Two Marble 1.1 worlds were generated, cached and loaded: a public-domain living room and a courtyard based on original procedural artwork. The courtyard's wide spectator view exposes floor stretching; the cleaner illustrative set is the default presentation scene. Generated worlds may contain invented details, artifacts and static foreground objects. The first draft had null metric metadata and was blocked. Generated geometry is not historical evidence.
- **No generated-mesh collision alignment.** Placement checks use a fixed map and conservative separate-prop bounds. They do not inspect a generated collider mesh. Static splat furniture cannot be picked up or removed as semantic objects. Review the composition before presenting it.
- **Local exploration state.** Gate opening and holding the keepsake are local. Accepted authored placements and source/history records synchronize. Full multiplayer physics is outside this foundation.
- **Local hosting.** The Mac, local Convex backend and HTTPS preview servers must stay awake and reachable. Self-signed certificates need acceptance on each device. No public URL, R2 storage, hosted database or Railway deployment was created.
- **Prototype media/privacy boundary.** Room membership and family-sharing checks gate new scene/transcript/media-link queries. Already obtained Convex file URLs are bearer capabilities, not expiring or individually revocable sessions. Sharing revocation cannot claw back a downloaded clip. Use fictional/permitted demo content; an external family service needs authenticated or expiring media, stronger invitations, per-contributor permissions and retention/export controls.
- **Spending.** World Labs has durable global/per-room submission caps and no automatic paid retry. The default three global submissions have been used by this review; cached worlds and their quality switches still work. Raising WORLD_LABS_GENERATION_LIMIT requires a deliberate operator decision. LLM/STT/TTS do not yet share the brief's centrally reconciled dollar/unit ledger. Short-lived browser speech tokens do not guarantee a hard aggregate audio budget. Use dedicated funded accounts/provider limits before broader access.
- **Performance evidence is bounded.** The production illustrative courtyard measured about 60 fps in headless Chrome on this Mac (120 sampled frame intervals). Full/lite generated worlds also reported approximately 60 fps in the checked desktop sessions. These are not physical-headset measurements. The approximately 9.4 MB IWSDK/Spark application chunk still produces a build warning.
- **Optional providers.** SHARP/Modal and Tripo adapters remain, but their live performance and output licenses were not reverified in this review. The default demo uses original props and World Labs and does not start a paid GPU worker.
- **Saved-memory tools.** Objects, accepted corrections, transcripts, original clips and events persist and can be inspected. A full history playback editor and portable authorized memory export are not complete.
- **Evaluation scope.** The 30-case set is internal, not an independent benchmark. The stored live run got 29/30 complete cases and zero unauthorized actions; one adversarial sentence lost an object. Offline mock understanding is weaker and visibly labeled.
- **Event eligibility.** This checkout has practice history. Preserve its dates and check current organizer reuse rules. Neither this build nor a test result guarantees a prize.
