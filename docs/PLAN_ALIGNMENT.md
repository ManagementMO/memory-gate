# Alignment with the Heirloom overnight brief

The source brief is outputs/heirloom-overnight/HEIRLOOM_OVERNIGHT_BUILD.md in the original planning workspace. It is a design/acceptance reference. Its launch instructions are not a new instruction to deploy, push, purchase, run indefinitely or submit to an event.

## Outcome

Level A's core browser collaboration is implemented and tested. Level B's real speech, original recording and generated scenery are implemented and exercised. Level C remains incomplete until a real Quest 3 wearer and a consenting family member review the flow.

The current user-directed focus is younger-onset Alzheimer’s, meaning diagnosis before 65, without assuming stage or ability. The shared construction/source/confirmation architecture is preserved. This refresh improves original garden geometry/materials, a steady eye-level camera, source-labeled spectator presentation, an optional phone 3D view and simpler storyteller controls. It removes the old grandparent/1940s assumptions and adds conservative uncertainty/quiz safeguards. Unpointed courtyard additions use bounded, spaced, provisional floor positions; unsupported model relations do not place objects on imagined furniture. If no clear slot remains, the words are kept without adding overlapping geometry. The backdrop’s authored architecture is interpretation, not extracted story evidence. Medical efficacy, individual comfort and patient usefulness are unverified; see LIMITATIONS.md and its research sources.

## Deliberate architecture changes

**Convex instead of SpacetimeDB plus a new Node server:** retain the supplied transactional identity, live subscriptions, scheduler and storage. Replacing a working backend would add integration risk without improving the core demonstration. No SpacetimeDB sponsor claim.

**Direct token-authenticated browser speech instead of server audio relay:** preserve the working AudioWorklet/manual-finalize path and its interruption/reconnect behavior. Backend membership/consent gates token issuance. A production audio service needs stronger aggregate quotas; tokens do not constitute a hard dollar budget.

**Guided spatial grammar before general model interpretation:** predictable English/Spanish beside/left/right/facing commands resolve current IDs and let ordinary code calculate transforms. Claude still handles free narration and translation. The guided path is labeled, not passed off as unrestricted LLM spatial reasoning.

**Original assets instead of missing generated/library files:** the supplied large model/splat fixtures were absent. Small original geometry creates a portable, licensed fallback without relying on the prior agent's machine or unclear generated-prop rights.

## Explicit gaps against the full brief

- Real Quest comfort/performance, physical mic and family language/content review.
- Collision alignment with a generated architecture mesh; arbitrary segmentation of static splat objects.
- Inline editing of a captured transcript before it is submitted.
- Recoloring an already accepted prop and arbitrary narration attachment to an existing selected object.
- Full accepted-history playback and authorized portable memory export.
- A unified reconciled LLM/STT/TTS/world dollar and unit budget.
- Expiring/authenticated media downloads, per-contributor permission records and production invite/rate-limit controls.
- A public durable deployment and deployment-specific restart validation.

These gaps are recorded rather than hidden behind green test counts. The coherent local foundation remains usable with procedural scenery and typed edits if a provider or optional dependency fails.
